# AI 时代共产主义知识库

一套面向研究、公共讨论与内容创作的开放知识库，围绕人工智能、区块链与前沿技术的发展，分析现实社会矛盾、生产资料与权力关系、劳动形态变化，以及可能的共产主义制度形态。

本库采用「理论—论题—素材—制度推演」四层结构。核心判断是：**AI、区块链、可控核聚变、合成淀粉、量子计算与太空技术都是能力变量，不会自动带来公共所有、公平分配或人的解放；制度效果取决于占有关系、公共权力、审计、更正、申诉与退出安排。**

当前知识库版本：**v4.18**。页面样张：**v0.5**。

## 知识库规模

- **8 条核心命题**：贯穿全库的主轴。
- **10 大主题轴、42 个论题簇**：每个论题簇包含核心问题、论点、理论依据、反驳预案与衍生选题。
- **51 条外部理论文献条目**：另设信息约束、目标函数、区块链与前沿技术等专题。
- **4 组前沿技术变量**：可控核聚变、合成淀粉、量子计算与太空技术，均按能力边界、工程成熟度、物质瓶颈、占有关系、治理条件和反证指标分析。
- **69 条术语**：统一中英译名及技术、制度和文化表征的边界。
- **6 个中国制度实践案例**：设置观察指标、否证案例与待验证问题。
- **8 条核心命题、3 条分叉路径、5 个风险开关**：对技术决定论和自动化乐观论保留反证条件。
- **8 项试点监测规格**：登记 B0 基线、C0 对照、成对指标、复核节奏、扩围条件与停止回滚动作。
- **33 张网页卡片**：用于快速理解核心观点，不是全库内容的替代品。

## 证据与推论等级

| 等级 | 含义 |
|---|---|
| **L-A** | 官方一手材料 |
| **L-B** | 同行评议研究 |
| **L-C** | 权威报告或官方转载 |
| **L-D** | 可靠媒体的二手材料 |
| **L-E** | 暂不可核验材料，不直接作为入库依据 |
| **L-K** | 本库内部推演，包括制度方案与试点方法设计 |

“定义”不纳入证据分级。引用数据时必须同时保留**时间点、统计口径和证据等级**；不得把政策目标写成实现结果，也不得把内部推演写成现实事实。

## 核心内容纪律

- **技术不替代制度**：区块链、可验证凭证、DAO、智能合约、通证和前沿技术都不自动等于公共所有或人的解放。
- **技术成熟度不可跨级**：实验室、工程系统、商业部署与公共服务分开登记；项目路线图、企业目标、物理量子比特数和发射次数都不能替代真实任务绩效。
- **前沿技术要过六关**：可复现能力、全系统成本、占有与可及、治理与救济、生态与安全、替代方案对照；缺一不得登记为公共成效。
- **先比较非链方案**：公共账本是否采用区块链，必须在同一任务、同一规模和同一口径下与普通签名文件、日志系统等方案比较。
- **可验证不等于真实**：账本只能证明某条记录符合既定验证规则，不能单独证明输入真实、规则正当或机构接受。
- **保留反证**：重要判断须配反对意见、停止条件与回滚方案，不能只列支持证据。
- **试点先锁基线**：B0 基线和 C0 对照缺失时，只能称为运行观察，不能称为政策有效。
- **数字统一登记**：数字口径以 L4 §2 与 L4-B 对应专节为唯一登记处，其他文档和页面只引用，不另立口径。
- **赛博朋克只作表征**：用于说明文化意象与风险界面，不作为因果证据；正式机制采用“平台依附固化”。
- **区分方案与结果**：八项试点是 L-K 方法设计，目前不表示试点已经启动、扩围或取得政策成效。

## 本地使用

本仓库以 Markdown 为主，可在 Obsidian、VS Code 或任意 Markdown 阅读器中打开。

```bash
git clone https://github.com/joeyoung610431-oss/ai-era-communism-kb.git
cd ai-era-communism-kb
```

打开 [AI时代共产主义知识库.md](AI时代共产主义知识库.md)作为全库入口。

交互页面是单文件原型，CSS 与 JavaScript 均内嵌，无外部依赖。下载或克隆仓库后，直接用浏览器打开 [site/index.html](site/index.html) 即可。该页面当前标记为 `noindex, nofollow`，属于设计样张，**尚未作为正式发布站部署**。

## 更新与贡献

1. 从全库入口确认应修改的文档层级与唯一数字登记处。
2. 新增事实必须附来源、时间和口径；新增方案必须标为推论并写明反证条件。
3. 修改核心命题、论题索引或页面卡片后，同步更新入口、版本记录及对应关系图。
4. 提交前检查相对链接、表格结构、代码块闭合与页面引用版本。
5. 不在提交中放入凭据、密钥、Obsidian 工作区状态、日志或临时文件；这些内容由 [.gitignore](.gitignore) 排除。

欢迎通过 Issue 或 Pull Request 提出文献补全、错误更正、论证加强与可视化建议。涉及现实政策效果、试点结果或公共数据变化的结论，请提供可复核来源。
